# GeckoUI Skills

Skills for building UIs with the GeckoUI component libraries (web + React Native).

## Installation

```
npx skills add GeckoUI/skills
```

## Available Skills

| Skill                                     | For                                      | Description                                             |
| ----------------------------------------- | ---------------------------------------- | ------------------------------------------------------- |
| [geckoui](./skills/geckoui)               | `@geckoui/geckoui` (web)                 | Component API, theming, and React Hook Form integration |
| [nativewind](./skills/nativewind)         | `@geckoui/nativewind` (React Native)     | Component API, theming, and override patterns for RN    |
| [nativewind-rhf](./skills/nativewind-rhf) | `@geckoui/nativewind-rhf` (React Native) | React Hook Form wrappers for `@geckoui/nativewind`      |
